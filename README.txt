=================================

FILES
- index.html: website content and structure
- styles.css: responsive black-and-gold design
- script.js: mobile navigation and automatic copyright year
- profile-photo.jpg: add your chosen portrait here (see below)

HOW TO ADD YOUR PORTRAIT
1. Use the exact portrait you chose (black suit, white shirt, black tie).
2. Rename the image file to: profile-photo.jpg
3. Put it in the same folder as index.html.
4. The site will show it automatically. If you don't add it yet, a neat OI placeholder appears.

PUBLISH WITH NETLIFY
1. Extract this ZIP first.
2. Open Netlify's manual deploy page: https://app.netlify.com/drop
3. Upload/drag the extracted website folder (or select the folder when prompted).
4. Netlify will provide a preview/live website link after deployment.
5. To update the portrait later, add profile-photo.jpg and upload the folder again.
